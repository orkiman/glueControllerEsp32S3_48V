# הקשר

אני בונה בקר חדש למערכת הדבקה בדבק קר במכונה תעשייתית. כרטיס הבקרה מבוסס
ESP32-S3 ויושב בתוך ארון שולחני מודפס בתלת-ממד (270x220 מ"מ, מכסה עליון משופע
ב-15° לכיוון המפעיל). אני רוצה להכניס למכסה מסך מגע שיהיה ממשק המפעיל, כך
שהמוצר יעבוד לבד בלי מחשב.

הארכיטקטורה כבר הוחלטה: מסך מגע עם מעבד ESP32 משלו (מה שנקרא "HMI display"
או "smart display"), שעליו ירוץ ממשק שייכתב ב-LVGL. המסך מדבר עם כרטיס הבקרה
בתקשורת טורית UART (3.3V, JSON בשורות). אני לא מחפש Raspberry Pi, טאבלט או
מסך HDMI.

# מה מצאנו עד עכשיו (מחיפוש, לא אומת מול דפי היצרן)

- Elecrow CrowPanel Advanced 10.1" — ESP32-P4 + ESP32-C6, 1024x600 לרוחב,
  257x163x10 מ"מ, כ-54-60$. המועמד המוביל.
- Waveshare ESP32-P4-WIFI6-Touch-LCD-10.1 — 800x1280 (במקור לאורך),
  246x156x12 מ"מ, מחיר לא ידוע.

# המשימה

1. אמת את הנתונים של שני המסכים האלה מול דפי היצרן, הוויקי ושרטוטי המידות.
2. חפש עוד 2-4 מועמדים שעומדים בדרישות (Elecrow, Waveshare, Sunton/"CYD",
   LilyGO, M5Stack, DFRobot, Makerfabs, Guition, Seeed וכו'), בגדלים 7" עד 10.1".
3. השווה והמלץ. אל תקנה ואל תוסיף לסל.

# דרישות (חובה)

- מעבד ESP32-P4 או ESP32-S3 על הכרטיס, עם דוגמאות LVGL רשמיות
  (ESP-IDF ו/או Arduino).
- מגע קיבולי.
- UART פנוי (TX/RX) נגיש על מחבר או פינים, שאינו תפוס על ידי USB או ה-WiFi.
  ציין את שם המחבר ומספרי ה-GPIO.
- הזנה מ-5V (יש לי ממיר 24V ל-5V). ציין דרך איזה מחבר ומה צריכת הזרם המקסימלית.
  כניסת 12-24V ישירה היא יתרון.
- מידות חיצוניות של המודול: רוחב עד 255 מ"מ, גובה עד 190 מ"מ,
  עובי עד 15 מ"מ (כולל מחברים בגב). חייבים שרטוט מידות עם חורי הרכבה.

# העדפות

- תצוגה לרוחב במקור (landscape).
- בהירות 300 nit ומעלה (סביבת מפעל מוארת), זווית צפייה רחבה (IPS).
- טמפרטורת עבודה עד 50°C לפחות.
- זכוכית קדמית / optical bonding.
- זמין למשלוח לישראל, עדיף מהיצרן או מ-AliExpress בחנות הרשמית.
- תיעוד טוב וקהילה פעילה; גרסת חומרה יציבה (בדוק אם דווחו באגים בגרסאות
  מסוימות, למשל בעיות WiFi בגרסה V1.1 של ה-CrowPanel).

# מה להחזיר

1. טבלת השוואה: דגם, מעבד, גודל ורזולוציה, כיוון, בהירות, מידות חיצוניות
   ועובי, חורי הרכבה, UART פנוי (מחבר + GPIO), הזנה וצריכה, טמפ' עבודה,
   מחיר כולל משלוח לישראל, קישור לדף היצרן ולשרטוט המידות.
2. המלצה אחת עם נימוק, וחלופה שנייה.
3. כל דרישה שלא הצלחת לאמת — סמן "לא נמצא" ולא לנחש.
